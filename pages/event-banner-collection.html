Graphic design

Event Banner Collection

Large-format event graphics designed for recognition, welcome, and a clear message at a distance.

ContextSkills festival & alumni gathering
FormatFreestanding event banners
FocusComposition, visual hierarchy & communication

01 / PURPOSE

A focused visual message.

Bring two event banner designs into one collection: the National Skill Festival 2019 graphic and the Madurai Medical College 1989 batch gathering. Each creates an identifiable event presence within a tall display format.

02 / DESIGN APPROACH

Shape, type, and image.

Prominent event names, strong colour fields, and emblem-led compositions establish a clear vertical reading order. The skills banner uses an energetic purple-to-red treatment, while the reunion design combines purple with gold anniversary details.

03 / DESIGN REASONING

Balance expression and clarity.

Large-format graphics need a different hierarchy from a hand-held page. The event identity must read quickly, with supporting details kept secondary and clear of the display’s lower edge. Decorative patterns add energy, but sufficient contrast and restrained text placement remain essential to legibility.
