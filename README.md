# Farzana Lodi — Design Portfolio

## Pages

- `index.html` is the home page, with a short introduction and three selected projects.
- `portfolio.html` is the full, filterable portfolio. It shows six projects per page in a three-column desktop grid.
- `pages/` contains the project and case-study pages.

## Assets and code

- `assets/images/thumbnails/` contains the project card artwork.
- `assets/images/photography/` is ready for the photography images.
- `assets/images/pdf-pages/` contains original page artwork retained from supplied PDFs.
- `css/style.css` contains shared styling and responsive layouts.
- `js/main.js` contains navigation, filters, pagination and lightbox behavior.

The site is framework-free. Open `index.html` in a browser; choose **View all work** to see the complete portfolio.
